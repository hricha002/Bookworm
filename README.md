# E-Book Store Web Application: Bookworm
<br>
It is an e-book website. It is an online book ordering system, that allows user to order book online as well as read the book online by purchasing it. Through meticulous design and development, we have created a platform that offers users a seamless and convenient way to browse select, and purchase books online. Our system not prioritizes users experience but also incorporates robust security measures to safeguard user data and transactions.
A dynamic online platform for purchasing and accessing e-books.

## 🚀 Tech Stack
- ASP.NET (C#)
- HTML, CSS, JavaScript, Bootstrap
- MySQL

## 📌 Features
- User Login/Register
- Browse Books by Categories
- Add to Cart & Purchase
- Admin Panel (Add, Update, Delete Books)
- Order Management
- Responsive UI

## 🧱 Database Structure
Tables:
- users(user_id, name, email, password)
- books(book_id, title, author, price, category, stock, Book_genre)
- orders(order_id, user_id, book_id, date, payment_status)

## 🔄 Workflow
1. User logs in  
2. Book catalog loads from MySQL  
3. User adds books to cart  
4. Order created and stored  
5. Admin manages book inventory  

## 📘 Learning Outcomes
- CRUD operations  
- UI/UX design  
- Session handling in ASP.NET  
- SQL-based backend management
